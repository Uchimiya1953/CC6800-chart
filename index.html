GitHubブラウザ画面だけでWebアプリ化する手順

ターミナルやPCの黒い画面を使わずに、ブラウザ操作だけで5分で公開できます。

ステップ 1: リポジトリの新規作成 GitHubの右上「+」アイコン →「New repository」をクリック。
Repository name に cc6800-app など好きな名前を入れ、Public のまま一番下の「Create repository」を押します。
ステップ 2: コードを新規作成して貼り付け 画面真ん中にある「creating a new file」リンクをクリック。
ファイル名入力欄に必ず index.html と入力し、下のテキストエリアにこのファイルの全コードをそのまま貼り付けます。
一番下の緑色ボタン「Commit changes...」を押して保存します。
ステップ 3: GitHub Pages（無料公開）をONにする リポジトリ上部の「Settings」タブ → 左メニューの「Pages」をクリック。
Build and deployment の Branch を「None」から「main (または master)」に変えて「Save」を押します。
🎉 完了！Webアプリとして起動 1分ほど待つと、Pages画面に専用URL（https://ユーザー名.github.io/cc6800-app/）が表示されます。
スマホやPCで開いて「ホーム画面に追加」をすると、アイコン付きの独立アプリとして使えます。
